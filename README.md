One emoji that stands for an AI agent: 🐙

An agent is many arms at once — parallel tools, parallel tasks, reaching
into many systems at the same time, while one head keeps the plan. The
octopus reads instantly at small size and says something specific about
how an agent works, instead of what it looks like. No robot, no smiley,
no brain.

[Your Agent in One Emoji on make.fun](https://make.fun/competitions/u-boge-your-agent-in-one-emoji-db30c1e4)

## How it works

`main.py` (Python 3.13, standard library only) writes the single emoji
to `/output/entry.txt`. Run it with `python3 main.py`, or check the
entry against the gate with `python3 main.py --check`.
